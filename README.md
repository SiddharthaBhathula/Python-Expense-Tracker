# 💰 Python Expense Tracker

> A lightweight and user-friendly command-line expense management application built with Python.

A command-line expense tracker that allows users to record, view, search, summarize, and delete their expenses. Expense data is stored locally in a JSON file, allowing it to persist between program executions.

---

## ✨ Features

- ➕ Add new expenses
- 📋 View all recorded expenses
- 🔎 Search expenses by category
- 📊 View spending summary
- 🗑️ Delete expenses
- 💾 Store expense data locally using JSON
- 🕒 Automatically record date and time
- 💰 Indian Rupee (₹) currency support
- ✅ Input validation
- ⚠️ Error handling
- 🔒 Keep personal expense data out of GitHub using `.gitignore`

💾 Data Storage

The application stores expense records locally in:

expenses.json

Example:

[
    {
        "id": "20260903184500123456",
        "amount": 500.0,
        "category": "Food",
        "description": "Lunch",
        "date": "03-09-2026 18:45"
    }
]

The JSON file is created automatically when an expense is added.

Why JSON?

JSON was selected because it is:

Lightweight
Human-readable
Easy to process with Python
Suitable for a small CLI application
Database-free
Easy to back up locally
🔐 Privacy

Expense information can contain personal financial data.

For this reason, the project includes a .gitignore file containing:

expenses.json

This prevents local expense records from being accidentally committed and pushed to GitHub.

Important: The application is intended for local personal use and is not a production-grade financial management system.
